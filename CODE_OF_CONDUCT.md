# Code of conduct

English · [Italiano](#codice-di-condotta)

Excido adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct, for issues, pull requests, discussions and any other project space.

In short:
- Be welcoming and patient.
- Assume good faith.
- Give and accept constructive feedback.
- No harassment, insults or personal attacks.

**Reporting.** If someone's behaviour makes you uncomfortable, use GitHub's
**Report content** option on the comment or issue, or contact the maintainers privately
through the [security advisory form](https://github.com/NewMediaDesign/excido/security/advisories/new)
(it is private, and not only for security problems). Reports are handled confidentially.

# Codice di condotta

[English](#code-of-conduct) · Italiano

Excido adotta il **[Contributor Covenant, versione 2.1](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/)**
in tutti gli spazi del progetto: issue, pull request e discussioni.

In breve:
- Sii accogliente e paziente.
- Presumi la buona fede.
- Dai e accetta critiche costruttive.
- Niente molestie, insulti o attacchi personali.

**Segnalazioni.** Per un comportamento scorretto usa l'opzione **Report content** di GitHub
sul commento o sulla issue, oppure contatta i maintainer in privato con il
[modulo degli advisory](https://github.com/NewMediaDesign/excido/security/advisories/new).
Le segnalazioni sono trattate in modo riservato.
